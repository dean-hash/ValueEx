# Sources — MVP

## Public Communities

- Reddit (target subs), Hacker News (Ask/Show), Stack Overflow (tagged Qs), GitHub (Issues/Discussions), YouTube comments, Product Hunt comments.

## Social-Lite (Public-Only; No Login)

- Facebook public groups/pages, TikTok public share pages, LinkedIn public posts/comments.
- Discovery: search operators → capture **permalinks** only. Store text, timestamp, engagement counts visible without login.

## Machine-Readable / Signals

- JSON-LD / Microdata / OpenGraph on any fetched page.
- Sitemaps/Feeds auto-discovery.
- Autocomplete (suggest endpoints) for **ambient demand** (store query + rank + time + geo bin).
- Google trends (daily; US + US-CA bins).

## Supply

- AWIN (API tested), Fiverr static links (3), CJ disabled.
- If a demand pattern lacks supply (e.g., travel/OTA not present), emit “onboard network/merchant” tasks (later agentic enrollment).

## Jurisdiction

- US-only; US-CA stricter (CPRA). EU/UK disabled.
